# 🧶 KnitCalc - Maschenrechner

Ein einfacher, mobil-optimierter Rechner für Strickprojekte. Hilft dabei, Maschenangaben aus Anleitungen (Soll) auf die eigene Maschenprobe (Ist) umzurechnen.


## 🚀 Funktionen
- **Maschenprobe-Rechner**: Gib deine Soll- und Ist-Maschenprobe ein.
- **Automatische Umrechnung**: Berechnet sofort den Umrechnungsfaktor.
- **10 Umrechnungs-Felder**: Genug Platz für alle Teile eines Pullovers (Bündchen, Ärmel, Ausschnitt, etc.).
- **Ganzzahlige Ergebnisse**: Alle Eingaben und Ausgaben sind auf ganze Maschen gerundet, um praktikable Strickwerte zu liefern.
- **Mobile First**: Design ist speziell für die Nutzung auf dem Smartphone optimiert.
- **Datenschutzfreundlich**: Funktioniert komplett lokal im Browser, keine Daten werden an Server gesendet.

## 🛠️ Technologien
- **HTML5** & **CSS3** (Modernes Glassmorphism Design)
- **Vanilla JavaScript** (Keine Frameworks, super schnell)
- **Responsive Design** für alle Displaygrößen

## 📦 Installation & Nutzung
Die App ist als statische Webseite konzipiert und kann direkt über **GitHub Pages** gehostet werden.

## 📝 Lizenz
Dieses Projekt ist ein privates Tool für Strickerinnen und Stricker.
